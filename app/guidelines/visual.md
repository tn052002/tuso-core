# The color philosophy

Instead of branding around the Five Elements, brand around **the sky**.

Why?

Because every culture understands the sky.

And the North Star lives in the sky.

Not in astrology.

Not in mysticism.

---

Not black.

Not navy.


* infinite
* calm
* premium
* timeless

# The biggest design advice

I actually think we should **avoid looking like an astrology app entirely**.

No purple.

No nebula.

No constellation overload.

No mystical gradients.

No tarot aesthetic.

Because your philosophy isn't:

> "The universe has secrets."

It's much closer to:

> **"Nature already knows how to move. So do you."**

That distinction should be visible before someone reads a single word.

## If I had to summarize the TUSO visual identity in one sentence:

> **Imagine if Apple designed a navigation instrument inspired by Lao Tzu rather than a horoscope app.**

I genuinely think that's the aesthetic space no one currently owns. It would make TUSO feel less like "ancient wisdom wrapped in modern UI" and more like **a timeless navigation system for living**.
